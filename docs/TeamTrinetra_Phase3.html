1. Core Functionality (10 marks)

Demo Video Link (backup): ______________________________

Trinetra AI is a citywide traffic intelligence prototype for ANPR, vehicle trajectory tracking, traffic analytics and intelligent enforcement.

The demonstration starts with operator login and a command-center dashboard showing 10 demo cameras, detected vehicle events, open alerts, congestion index and a GIS map. A vehicle number can be entered in Live Tracking to retrieve its multi-camera trajectory. The route is displayed with road-following geometry, direction arrows, START and LATEST markers, and a camera timeline.

An operator can add a registration number to the blacklist with a reason. When a blacklisted vehicle is detected through the ANPR workflow, the backend creates a high-severity alert, stores it, sends a WebSocket notification to connected dashboards and plays an alert beep. The prototype also includes ANPR event monitoring, uploaded video ANPR, traffic analytics and an E-Challan demonstration workflow.

2. UI/UX (5 marks)

Attach screenshots of: Login, Dashboard, Live Tracking, Blacklist, Alert popup, Traffic Analytics and E-Challan.

The interface uses a command-center layout so operators can scan important information quickly. Persistent sidebar navigation keeps workflows discoverable. Summary cards highlight active cameras, detections, alerts and congestion. Maps, direction markers and a timeline make vehicle movement easier to understand. Forms provide clear feedback for invalid input and duplicate blacklist entries. The layout supports smaller screens and light/dark themes.

4. Performance (5 marks)

The Vite production build completes in approximately 1-2 seconds on the development machine. Dashboard API requests are loaded in parallel. The prototype was tested with 10 cameras, 10 demo vehicles and five trajectory points per vehicle. WebSocket alerts are delivered to connected clients. Route arrows are limited to avoid visual overload. If routing or WebSocket services are unavailable, the UI keeps working with fallback/status behavior.
